## 学び

CPU は ROM(命令メモリ) と RAM (メモリ＋I/Oメモリマップ) と連携して処理を行う。

CPU のプログラムカウンタの値をもとに、 ROM 命令メモリから命令データを取り出す。
このとき、命令データは 2^16 のバイナリで表現されており、該当の CPU のプロトコルに沿った内容である必要がある。

ROM 命令データと、後述するメモリRAMデータを入力にして、 CPU は計算を行う。
計算には ALU と A, M, D レジスタを利用している。
A, M, D レジスタは CPU が内部的にもつ一時記録場所であり、 少しのデータしか持てない代わりに CPU とすぐに連携できる。

ALU で計算されたのち、 ROM と RAM にむけてそれぞれデータを送る。
ROM については、プログラムカウンタの値を送り、次に読み出したい命令データを決める。
多くの場合は +1 したアドレスを送るが、 Jump を行う場合はそのジャンプ先のアドレスを送る。

一方で、 RAM には書き込みたいアドレスと、書き込みたい値、あとはそもそも書き込むかというフラグを送る。
その後 RAM が内部的に書き込み処理を行う。
その後 CPU が RAM から値を取り出す。

このサイクルを命令データをすべて処理するまで行う。
